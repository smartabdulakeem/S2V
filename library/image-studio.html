Image Studio

Browse and choose here — a script does the downloading. Generate opens a preview so you can judge a prompt before committing. Tick the ones you want, hit Export, and one command fetches them all into library\images\.

Three steps. You never save an image by hand:

1. Mark all on the batches you want (or tick individual rows).
2. Export ticked → Copy command.
3. Paste it into a terminal in S2V\ and leave it running.

Generate on a row is just a preview, so you can judge a prompt before committing. It does not save anything — the command in step 3 does all the downloading.

Skip the page entirely if you like: python tools/fetch_batches.py --theme I or --tier q or --all.

Two quality tiers. Batches tagged IMAGEN contain human subjects — faces, hands, crowds. The fetcher routes those to Google Imagen 4.0, which handles people far better than Pollinations. Batches tagged BULK are landscapes, objects and architecture, where free Pollinations is indistinguishable. Imagen needs your Google key in config\settings.json; without it everything falls back to Pollinations.

Split with Antigravity: Antigravity works the list from the top (Desert terrain downward). You work from the bottom (Motivation upward). Use the Theme filter to jump to your end.
