When disabled (recommended), script narration is split in Python with zero LLM calls. Here is what is affected:

  • voice_steering per segment is lost. This is the only real loss.
  • Shot query falls back to keyword extraction (2–3 words). Image retrieval prefers visual_description when present, so the visual impact is minimal.
  • Shots per segment falls back to the rhythm slider, which you control directly.
  • Segmentation is completely unaffected.

Keys are stored on this machine only, in config/settings.json, and never travel with the app. Everything except cloud prompt writing and cloud TTS runs offline and needs no key at all: local narration, image retrieval, captions, and rendering are all local.
